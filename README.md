# ASU Senior Engineer Assessment

A take-home system design exercise for the Senior AI Cloud Engineer role. There is no code to
run: you write a design document, then walk us through it live.

## What to do

1. Read [ASSESSMENT.md](./ASSESSMENT.md). It has the scenario, the rules and the sections we
   expect.
2. Write your design as one Markdown or PDF document, using the section numbers in the brief.
3. Send it as a reply to the message that invited you, by the due date.

Don't commit your document to a fork or put it in any public repository.

## Timeline

| | |
|---|---|
| Work | About 6 hours |
| Clarifying questions | Up to three, as a reply to the invitation, within the first 72 hours |
| Due | 7 calendar days after you receive this |
| Follow-up | A 60-minute session, without AI tools, where you walk us through your design |
